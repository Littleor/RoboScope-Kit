# Custom-image validation demos

This directory contains engineering demos for validating RoboScope's
user-owned custom-image path across representative model architectures and
Benchmark action contracts.

Each demo records validation evidence for the generic SDK and custom-image
workflow. Product documentation and the image catalog remain the source of
truth for model-specific official image support.

- `xvla/`: exercises one multi-Benchmark X-VLA custom image and its
  model-specific observation and action adapters.
